About This Analysis

This analysis visualizes mobile network performance data from Ookla Speedtest for Q3 2025 around MetLife Stadium.

Coverage Area: ~1km radius from stadium center
Time Period: Q3 2025 (July 1 - September 30, 2025)

How to Run with Actual Data

To analyze actual Ookla Q3 2025 data:

  1. Open MetLife_Stadium_Ookla_Analysis.ipynb in Google Colab
  2. Run all cells - the notebook will download the ~185MB parquet file
  3. The visualization will be generated with real data

Or run locally:

python metlife_ookla_analysis.py
